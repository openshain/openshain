# PDF の fixture

`pdf_read` のテストが読む PDF です。3 つとも架空の会社のもので、手で組んだ PDF の構造そのものです。フォントの本体は入っていません(文字の取り出しは、フォントの絵ではなく ToUnicode の対応表を通るためです)。

| ファイル | 中身 | テストで確かめること |
|---|---|---|
| `invoice.pdf` | 2 ページの請求書。Type0 / Identity-H に ToUnicode を付けたもの。生成系が出す普通の形です | 日本語が文字として取り出せること。ページの窓が効くこと |
| `old-cmap.pdf` | 外部の文字マップ(`UniJIS-UCS2-H`)を使い、フォントを埋め込んでいないもの | 文字はあるがフォントを読めない、と伝えること |
| `scan.pdf` | 四角を 1 つ描くだけで、文字の命令が 1 つも無いもの。紙を撮った PDF の代わりです | 文字が入っていない、と伝えること |
