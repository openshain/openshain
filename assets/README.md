# assets

openshain のロゴです。README とサイトで使います。

| ファイル | 用途 |
|---|---|
| `openshain_horizontal_lockup_*` | 印と文字を横に並べた形です。README の先頭はこれです |
| `openshain_vertical_lockup_*` | 印の下に文字を置いた形です。正方形に近い場所に |
| `openshain_logomark_*` | 印だけです。アイコンやアバターに |
| `openshain_wordmark_*` | 文字だけです |

`color` は緑の印と濃紺の文字、`black` と `white` は単色です。暗い背景には `white` を使います。SVG が原本で、PNG は書き出しです。

ロゴは openshain を指す用途に限ります。このリポジトリのライセンス(Apache-2.0)は商標の使用を許諾しません(第 6 条)。
